# 批量导入个人预算

入口：“个人预算与应用统计” → 批量导入。仅导入用户配置，应用统计仍由模型调用生成。

## 使用

1. 下载 CSV 模板，用 Excel 编辑后另存为 **CSV UTF-8**。
2. 填写用户标识、所属部门、档位；用户标识列设为文本以保留前导零。
3. 部门须已存在；留空档位或填 inherit 表示继承部门。显式档位仅支持 L1/L2，部门可为空；此时导入会清除该用户原部门关联。
4. 选择文件，预览校验通过后确认新增/更新，再点击确认导入。
5. 查看每行结果；失败及未完成项可重试，成功项不重复提交。下载 JSON 结果保存各行工单。

限制：最多 200 条、1 MB。支持 UTF-8 BOM、CRLF、引号转义和英文表头 `subject,department,tier`。不支持直接上传 XLSX。重复用户、非法档位、无效部门、错误 CSV 格式会在写入前拒绝。

更新沿用插件 assign：保留已消费及加量，替换基准档位。逐条生效，非整批事务；处理中不要刷新页面。同一弹窗的失败重试沿用相同工单和请求体。遇到鉴权失败或周期/工单冲突停止后续行；周期切换需下载结果后重新预览。关闭/刷新后不自动恢复任务，可凭结果文件中的工单核对。

## 实现文件

| 文件 | 改动 |
|---|---|
| src/main.jsx | 页面增加批量导入按钮，导入后刷新账户数据 |
| src/BulkImport.jsx | 模板下载、文件校验、预览、确认、逐行结果与结果下载 |
| src/import.mjs | CSV 解析、业务校验、稳定工单生成、失败重试 |
| src/style.css | 导入抽屉、预览表格、手机布局 |
| tests/import.test.mjs | 解析边界、重复用户、限额、幂等重试与停止逻辑 |
| tests/browser-import.mjs | 真实 Portal/网关导入和网络失败重试 |
| package.json | npm test 包含导入单元测试 |

无需修改网关插件：仍通过带登录/CSRF 的 BFF 调用插件 assign；每行工单前缀为 IMPORT，变更进入原审计账本。没有提供可绕过管理员鉴权的新接口。

## 自动调试执行

在 higress-console/portal 执行：

```bash
node --test tests/import.test.mjs
npm test
npm run build
node tests/browser-import.mjs
```

结果：18 项单元/接口测试（含新增 6 项）通过，9 项浏览器检查通过，生产构建通过。

浏览器测试真实创建两名用户：一名个人 L1、一名部门继承；模拟第二行网络中断，验证结果 1 成功/1 失败，再重试验证只发送失败行且工单不变。最后直接查询插件核对个人/部门来源与独立付款主体。
